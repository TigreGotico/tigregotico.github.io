## Die Kurzfassung

Diese Website erhebt **keine personenbezogenen Daten**. Keine Cookies, keine
Analyse, keine Tracking-Pixel, keine Webformulare, keine Einbettungen von
Dritten. Wir bauen Sprachtechnologie mit Fokus auf Privatsphäre, und unsere
eigene Website hält denselben Standard ein.

## Was diese Seite tut

- **Nur statische Seiten.** Die Seite ist einfaches HTML/CSS, das von GitHub
  Pages ausgeliefert wird. Es gibt keinen serverseitigen Code von uns und keine
  Datenbank.
- **Keine Cookies.** Ihre Wahl von Design und Farbpalette wird im
  `localStorage` Ihres Browsers gespeichert — sie verlässt niemals Ihr Gerät und
  enthält keine identifizierenden Informationen.
- **Selbst gehostete Schriften und Ressourcen.** Jede Ressource auf normalen
  Seiten wird vom eigenen Ursprung dieser Seite ausgeliefert; keine Anfragen
  gehen an Google, CDNs oder Werbenetzwerke.
- **Keine Analyse.** Wir zählen Sie nicht, erstellen keinen Fingerabdruck von
  Ihnen und beobachten nicht, was Sie lesen.

## Hosting

Die Seite wird von **GitHub Pages** (GitHub, Inc.) ausgeliefert. Wie jeder
Webhoster kann GitHub technische Standarddaten (IP-Adresse, User Agent)
protokollieren, um den Dienst zu betreiben und zu sichern; siehe die
[GitHub-Datenschutzerklärung](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
für Einzelheiten. Wir haben keinen Zugriff auf diese Protokolle und bewahren
keine Kopie davon auf.

## Die Stimmen-Demo

Die interaktive [Text-to-Speech-Demo](/demo) läuft **vollständig in Ihrem
Browser**. Nichts, was Sie eingeben, wird an uns gesendet. Wenn Sie eine Stimme
auswählen, lädt Ihr Browser die offenen Modelldateien von
[Hugging Face](https://huggingface.co) herunter, was der
[Datenschutzrichtlinie von Hugging Face](https://huggingface.co/privacy)
unterliegt. Die Synthese selbst findet auf Ihrem Gerät statt.
