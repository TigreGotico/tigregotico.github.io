## La versione breve

Questo sito web non raccoglie **alcun dato personale**. Niente cookie, niente
analitica, niente pixel di tracciamento, niente moduli web, niente contenuti
incorporati di terze parti. Costruiamo tecnologia vocale che mette la privacy al
primo posto, e il nostro sito web è tenuto allo stesso standard.

## Cosa fa questo sito

- **Solo pagine statiche.** Il sito è semplice HTML/CSS servito da GitHub Pages.
  Non c'è codice lato server nostro né alcun database.
- **Niente cookie.** Le tue scelte di tema e palette di colori sono memorizzate
  nel `localStorage` del tuo browser — non lasciano mai il tuo dispositivo e non
  contengono alcuna informazione identificativa.
- **Font e risorse self-hosted.** Ogni risorsa sulle pagine normali è servita
  dall'origine stessa del sito; nessuna richiesta va a Google, CDN o reti
  pubblicitarie.
- **Niente analitica.** Non ti contiamo, non creiamo impronte digitali del tuo
  browser, né osserviamo cosa leggi.

## Hosting

Il sito è servito da **GitHub Pages** (GitHub, Inc.). Come qualsiasi host web,
GitHub può registrare dati tecnici standard (indirizzo IP, user agent) per
gestire e proteggere il servizio; consulta la
[Dichiarazione sulla privacy di GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
per i dettagli. Non abbiamo accesso a quei registri né ne conserviamo copia.

## La demo delle voci

La [demo interattiva di sintesi vocale](/demo) gira **interamente nel tuo
browser**. Niente di ciò che digiti ci viene inviato. Quando scegli una voce, il
tuo browser scarica i file aperti del modello da [Hugging Face](https://huggingface.co), che è
soggetto alla [politica sulla privacy di Hugging Face](https://huggingface.co/privacy).
La sintesi stessa avviene sul tuo dispositivo.
